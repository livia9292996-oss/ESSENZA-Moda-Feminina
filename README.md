# ESSENZA Moda e Beleza

Site institucional de uma empresa fictícia do ramo de **moda e beleza femininas**, desenvolvido como atividade prática da disciplina de Web Frontend.

## Aluna

Livia Silvana Oliveira

## Sobre o projeto

A ESSENZA Moda e Beleza é uma empresa fictícia que oferece roupas, acessórios, maquiagem, perfumaria, cuidados com a pele e consultoria de estilo. O site apresenta a empresa, sua missão, visão e valores, seus produtos e serviços e um formulário de contato.

## Páginas

- `index.html`: página inicial, com carrossel de imagens e botão "Voltar ao topo"
- `sobre.html`: informações institucionais (missão, visão e valores)
- `servicos.html`: produtos e serviços oferecidos
- `contato.html`: formulário de contato, endereço e telefone

## Tecnologias e recursos utilizados

- HTML5
- CSS3, com layout responsivo (Media Queries) e paleta preto e dourado
- JavaScript
  - validação do formulário de contato (campos preenchidos e formato do e-mail)
  - botão "Voltar ao topo" com rolagem suave
  - carrossel de imagens rotativo
- Git e GitHub para versionamento
- GitHub Pages para publicação
- Linux (terminal) e Visual Studio Code
